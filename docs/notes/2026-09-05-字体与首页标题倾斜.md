# 2026-09-05 字体优化与首页标题倾斜

## 背景

用户反馈：首页标题「字体可以稍微倾斜，用一些好看一点的字体」。

## 改动

### 1. 全局字体栈（`web/src/styles/main.css`）

引入展示字体 Inter（Google Fonts 在线引入），中文回退到系统无衬线，替换原 IBM Plex Sans。

```css
--font: 'Inter', 'HarmonyOS Sans SC', 'PingFang SC', 'Microsoft YaHei', 'Hiragino Sans GB', system-ui, sans-serif;
--font-display: 'Inter', 'HarmonyOS Sans SC', 'PingFang SC', 'Microsoft YaHei', system-ui, sans-serif;
--mono: 'IBM Plex Mono', ui-monospace, monospace;
--letter-tight: -0.04em;
```

`web/index.html` 增加 Google Fonts 预连接与 Inter 资源（权重 400-900）。

### 2. 主标题倾斜（`web/src/views/HomeView.vue`）

主标题 `.hero-title`：
- `font-family: var(--font-display)`、`font-weight: 800`
- `letter-spacing: var(--letter-tight)`（-0.04em）
- `transform: skewX(-4deg)` 整体轻微倾斜

**中文不用 `font-style: italic`**：中文字形假斜体会发虚，故用 `skewX` 倾斜整个字形，视觉统一更精致。

### 3. 关键坑：入场动画覆盖倾斜

`.hero-title` 用了 `.enter` 入场动画（`heroIn`），其 `to` 帧写 `transform: none` 会覆盖 `skewX`。解决：为 `.hero-title.enter` 单独定义 `heroTitleIn` 关键帧，位移/模糊入场的同时保留 `skewX(-4deg)` 末帧。

## 验证

- `npm run build` 通过
- CDP 读取计算样式确认：`font-family: Inter...`、`font-weight: 800`、`transform: matrix(1,0,-0.0699,1,0,0)`（即 skewX(-4°)）
- 浏览器截图确认标题整体轻微左斜、字距收紧、视觉更精致
