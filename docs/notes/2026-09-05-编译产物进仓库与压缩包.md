# 2026-09-05 编译产物进仓库与压缩包（部署不再编译）

## 背景

用户要求：前端 + 后端编译产物（`server/dist` + `web/dist`）**同时 push 到 git 仓库** 和 **打进压缩包**，部署服务器上**不再编译**（不跑 tsc/vite）。

## 关键改动的坑

### 1. `.gitignore` 取反 dist
原 `.gitignore` 有 `dist/` 与 `web/dist/`，会把编译产物排除在 git 外。gitignore 是**顺序敏感**的：`web/dist/`（单独规则）会覆盖前面的 `!web/dist/`。需调整为：

```gitignore
dist/
!server/dist/
!web/dist/
```
并**移除**后面那条 `web/dist/`，否则取反失效。最终 `server/dist`、`web/dist` 可被跟踪，`node_modules/.env/data/*.log` 仍被忽略。

### 2. `pack-sseinfra.ps1` 剔除日志
zip 里之前混入了 `server/*.log`、`web/*.log`。给 `Copy-Tree` 增加按正则排除的能力：

```powershell
function Copy-Tree {
    param([string]$Src, [string]$Dst, [string[]]$ExcludeNames, [string[]]$ExcludeRegex)
    ...
    foreach ($pat in $ExcludeRegex) {
        if ($it.Name -match $pat) { $skip = $true; break }
    }
}
```
调用时传 `-ExcludeRegex @('\.log$')`。

> ⚠️ 坑：`-match` 用的是**正则**不是 glob！`'*.log'` 会报 `ArgumentException`（`*` 是重复量词但前面无字符）。必须写成 `'\.log$'`。且调用处的命名参数名需与函数定义一致（`-ExcludeRegex`），否则 PowerShell 静默不生效。

### 3. deploy.sh 不需改
zip 已含 `server/dist/index.js` 与 `web/dist/index.html`，deploy.sh 检测到 dist 存在时会**跳过编译**，只 `npm ci --omit=dev` 装生产依赖。前端走相对路径 `/api`（deploy.sh 已注入 `VITE_BASE_PATH=/`、`VITE_API_BASE=`）。
