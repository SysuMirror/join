# 部门系统、UniSSO 登录与简历中心（2026-10-26）

## 本次改动

1. **部门系统**：新增 `departments` 表；岗位必须归属部门；首页展示部门卡片；岗位列表按部门/方向/类型/地点筛选。
2. **UniSSO 登录**：报名同学统一使用集市身份登录（Authorization Code + PKCE S256 / OIDC），首次登录按 `sub` 自动建号；管理员邮箱验证码保留为备用。
3. **简历中心**：在线简历 + PDF 上传解析；报名必须登录并选择简历；个人中心查看报名与 OA 进度。
4. **Q&A**：新增 `/faq` 页面与后台问答管理；首次初始化播种常见问题。
5. **部门管理员**：部门可配置管理员邮箱；部门管理员只能管理自己部门的岗位与报名。
6. **首页改版**：不再直接列岗位，改为「查看招新岗位」入口 + 部门/流程/FAQ 预览。

## 数据模型新增

- `departments`：`name/slug/summary/description/color/admin_emails/enabled/sort_order`
- `jobs` 扩展：`department_id/direction/experience/education/salary/tags/responsibilities/requirements/bonus`
- `resumes`：基本信息、教育、工作/项目、技能、自我评价、PDF 路径、解析文本、`is_default`
- `applications` 扩展：`user_id/resume_id/email/phone/resume_snapshot`
- `faqs`：`category/question/answer/sort_order/enabled`
- `sso_states`：一次性 `state` + PKCE verifier（10 分钟过期）
- `users` 扩展：`sso_sub/sse_sub/internal/avatar/roles/provider`

旧数据在启动时自动迁移；旧岗位里的部门名会自动生成部门记录。

## UniSSO 注册参数（交给平台管理员）

在 https://sso.ssemarket.cn/admin/apps 注册：

- 应用名：`软工集市 · 招新`
- Redirect URI：`https://join.ssemarket.cn/api/auth/sso/callback`
- 本地联调（可选）：`http://localhost:8091/api/auth/sso/callback`
- Scopes：`openid profile:username profile:name profile:avatar profile:student_id email`
- Confidential：`true`
- Icon：`https://join.ssemarket.cn/logo.png`

注册后注入：

```ini
UNISSO_ISSUER=https://sso.ssemarket.cn
UNISSO_CLIENT_ID=...
UNISSO_CLIENT_SECRET=...
UNISSO_REDIRECT_URI=https://join.ssemarket.cn/api/auth/sso/callback
UNISSO_SCOPES=openid profile email
```

`redirect_uri` 必须完全一致；`client_secret` 只放服务端。

## 权限作用域

- 超级管理员：`JOIN_ADMIN_EMAILS` + 站点配置 `adminEmails`。
- 部门管理员：`departments.admin_emails`（逗号分隔）。
- 后台 `requireStaff` 放行两类角色；`getAdminContext()` 计算可管辖部门。
- 部门管理员：
  - 可查看/新建/编辑/关闭本部门岗位；
  - 可查看/通过/驳回本部门报名；
  - 不能管理其他部门、部门管理员名单、问答、站点配置。
- 全局管理接口（部门 CRUD、站点、问答）走 `requireGlobalAdmin`。

## 登录流程实现

- `GET /api/auth/sso/start?returnTo=...`：生成 state + PKCE，302 到 UniSSO。
- `GET /api/auth/sso/callback`：校验 state（一次性）→ 换 token → 校验 id_token（RS256/JWKS/iss/aud/exp）→ userinfo → 按 `sub` upsert 用户 → 写 HttpOnly `join_session` Cookie → 302 回 returnTo。
- 会话 token 仍为 HMAC-SHA256（7 天）；前端同时兼容旧 localStorage Bearer token。
- 不把 UniSSO access token 当本应用会话；`sse_sub` 仅保存为外部 id。
- 登出只清本应用 Cookie；UniSSO 侧会话不受影响。

## 简历上传/解析

- 前端 FileReader → base64 JSON → `POST /api/me/resumes/upload`。
- 后端校验 `%PDF-` magic、大小（默认 10MB）、页数（默认 30）。
- `pdfjs-dist` legacy 构建提取文本；`resume-parse.ts` 启发式预填字段。
- 文件保存到 `DATA_DIR/uploads/resumes/<userId>/<uuid>.pdf`；下载接口仅本人或管理员可访问。
- 扫描件/图片型 PDF 提取不到文本时保存文件并提示手填。

## 部署步骤

1. 备份 `~/data/join-store.json`。
2. 构建：`cd server && npm run build`；`cd web && npm run build`。
3. 在平台部署配置中注入 `UNISSO_*`（以及原有的 `JOIN_*`/SMTP）。
4. `supervisorctl -c ~/deploy/supervisord.conf restart deploy-JyekPlhqwQ`。
5. 首次启动会自动迁移数据并播种部门/FAQ。
6. 用超级管理员登录后台 → 部门 → 填写部门管理员邮箱；部门管理员用 UniSSO 登录即可进入后台。
